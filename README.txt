Daily Quest - 更新版

GitHub Pagesへの設置
1. ZIPを展開します。
2. daily_questフォルダ内の index.html / manifest.json / sw.js を、GitHubリポジトリの公開フォルダにアップロードして置き換えます。
3. 公開ページを再読み込みします。Service Workerのキャッシュ名を更新しています。

重要：更新前にアプリの「バックアップ」→「書き出す」でJSONを保存してください。

データについて
- 保存先は利用中のブラウザのlocalStorageです。別端末・別ブラウザには自動同期されません。
- 旧版の保存キー lifeImprovementTasks.v1 を読み込み、新しい形式へ移行します。
- JSONバックアップの読み込みは現在のデータを置き換えます。
- 親タスク削除時は、完了済みサブタスクの実績ポイントを保持します。

機能
- 行動ポイント1〜3
- 親タスク・サブタスク
- 自動並び替え、進捗表示、実績集計
- 日付別の完了履歴と再開操作
- JSONバックアップ・復元
